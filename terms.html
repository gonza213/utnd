1. Finalidad del sitio

Este sitio es informativo y permite solicitar contacto para responder consultas sobre servicios de seguros y planificación.

2. Mensajería (SMS)

Solo se enviarán mensajes SMS informativos si el usuario otorga su consentimiento explícito mediante el checkbox del formulario. La frecuencia puede variar. Pueden aplicar tarifas de mensajes y datos. Para cancelar, responder STOP. Para ayuda, responder HELP.

3. Uso aceptable

El usuario se compromete a brindar información veraz y a no utilizar el sitio para fines ilegales.

4. Contacto

Si necesitás asistencia, usá los canales oficiales publicados en el sitio.
